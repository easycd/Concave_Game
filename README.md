# 오목

TypeScript + React + Node.js + Socket.IO로 만든 실시간 온라인 오목 게임입니다.

## 실행

Node.js 22 이상을 사용하세요.

```powershell
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 다른 브라우저/시크릿 창에서 접속하면 여러 명의 플레이를 확인할 수 있습니다. 같은 네트워크의 친구는 `http://서버PC의내부IP:5173`으로 접속할 수 있으며 방화벽에서 해당 포트의 접근을 허용해야 합니다. 외부 친구와 인터넷으로 플레이하려면 서버를 공개 호스팅에 배포해야 합니다.

## 빌드 및 서버 실행

인터넷 공개 배포 설정과 단계는 [DEPLOY.md](./DEPLOY.md)에 정리되어 있습니다. Render용 `render.yaml`과 Dockerfile이 포함되어 있습니다. 운영 서버는 TypeScript를 컴파일한 JavaScript를 Node.js로 실행합니다.

```powershell
npm run build
npm start
```

서버가 http://localhost:3001 에서 빌드된 웹 화면과 실시간 연결을 함께 제공합니다. 환경 변수 `PORT`로 포트를 변경할 수 있습니다. WebSocket을 지원하는 Node.js 호스팅에 이 폴더를 배포하고 빌드 명령은 `npm ci && npm run build`, 실행 명령은 `npm start`로 설정하세요. 서버를 여러 인스턴스로 확장하는 기능은 포함하지 않았습니다.

## 플레이

1. 닉네임을 정합니다(1~12자).
2. 1대1 또는 2대2 방을 만들거나, 6자리 코드로 입장합니다. 방 안에서 초대 링크를 복사할 수 있습니다.
3. 대기 중 빈 자리를 눌러 팀을 이동할 수 있습니다. 관전자는 방마다 최대 3명이며 채팅할 수 있습니다. 자리 이동 시 준비 상태가 초기화됩니다.
4. 모든 플레이어가 준비하면 방장이 대국을 시작합니다.
5. 각 팀 첫 번째 플레이어(1번/2번)가 10초 안에 가위바위보를 선택합니다. 이긴 팀은 흑돌입니다. 무승부·양쪽 미선택은 재시도하며, 한쪽만 선택하면 그 팀이 승리합니다. 선택 내용은 두 팀이 선택하기 전에는 공개되지 않습니다.
6. 1·3번은 1팀, 2·4번은 2팀입니다. 1팀이 선공하면 1→2→3→4, 2팀이 선공하면 2→1→4→3 순서입니다. 같은 팀의 돌을 함께 연결합니다.
7. 방 생성 시 5~300초로 정한 제한 시간을 두 모드 모두 매 차례 적용하며 시간 초과 시 해당 팀 패배입니다. 가로·세로·대각선으로 5개 이상 연결하면 승리하며, 금수는 없습니다.
8. 대국 중 기권·퇴장은 팀 패배입니다. 연결이 끊기면 20초 동안 자리를 보존하고 재연결을 기다립니다. 제한 시간은 계속 흐르며, 20초가 지나면 퇴장 처리합니다.
9. 종료 후 방장이 다음 대국을 준비할 수 있습니다. 마지막 플레이어가 퇴장하면 관전자는 로비로 돌아가고 방은 삭제됩니다.
10. 타이머 바와 중앙 차례 표시로 현재 플레이어를 확인합니다. 내 차례에는 바둑판 테두리가 초록색으로 빛납니다. 채팅은 전송 간격 제한 없이 착수와 독립적으로 전송됩니다.

바둑판은 사용자가 제공한 원본 이미지를 `public/board.png`에 저장하여 사용합니다. 모바일에서는 바둑판과 참가자·채팅을 세로로 배치합니다.

## 검증

```powershell
npm test
npm run build
```

게임 규칙 단위 테스트와 실제 Socket.IO 클라이언트 8개를 사용하는 통합 테스트가 포함되어 있습니다. 서버가 차례·착수 위치·승리·시간 제한·자리 이동·관전자 수를 검증합니다.

## 현재 데이터 보관 방식

방·대국·채팅은 서버 메모리에 보관합니다. 서버 재시작 시 초기화됩니다. 로그인·영구 전적·DB 저장은 포함하지 않았습니다. 브라우저 탭의 세션 저장소에 접속 토큰을 보관하여 잠깐의 연결 끊김/새로고침에 같은 자리로 복귀합니다.

구현 시 참고: [Socket.IO 공식 서버 문서](https://socket.io/docs/v4/server-api/), [Vite 공식 서버 옵션 문서](https://vite.dev/config/server-options).

대국 기록은 상단의 대국 기록 버튼에서 확인하며 착수 순서대로 다시 볼 수 있습니다. 기록은 접속 중 브라우저 메모리에만 보관하고 새로고침하거나 사이트를 떠나면 삭제됩니다. 방 코드 복사는 6자리 코드만, 초대 링크 복사는 입장 주소를 복사합니다.
